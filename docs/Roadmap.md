# Roadmap

## Implemented in 0.1.x

- Local Windows evidence collection across 21 sections.
- Explainable support/security triage and six guided procedures.
- Offline report, ticket notes, KB drafts, bundle and hash manifest.
- Local/share profiles and separately confirmed repair actions.
- Process-scoped PowerShell launch and writable temp defaults.
- Schema validation, failure messages, timeout, output preflight and coverage comparisons.
- Source publication guard and configured cross-platform/Windows CI.

## Next: validate and improve the local release

- Run the hosted Windows parser/collector checks and record actual outcomes.
- Review the report visually in Edge/Chrome and at narrow widths.
- Add more real lab cases using sanitized or fictional evidence.
- Test optional/unsupported Windows components and third-party antivirus scenarios.
- Improve per-probe timeout/status detail and per-section collection timings.

## Later, subject to design and test evidence

- Microsoft 365/Outlook-specific support workflows.
- Read-only AD diagnostics when RSAT and domain permissions are available.
- Process hash/signature evidence for security triage.
- Additional battery/storage checks where reliable providers exist.
- Persistent local incident/KB storage.
- Remote/fleet collection with explicit authentication and authorization design.

No schedule is promised. Unimplemented items should not be presented as completed portfolio features.
